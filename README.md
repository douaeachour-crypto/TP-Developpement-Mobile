# Android Calculator

A calculator application developed in Android Studio using Java.

This project was created as part of my Mobile Development coursework to practice Android application development, user interface design, and event handling.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage calculation
- Positive and negative numbers
- Decimal numbers
- Clear and reset functions
- Continuous expression display
- Error handling

## Technologies

- Java
- XML
- Android Studio
- Android SDK

## Concepts Practiced

- Android Activities
- XML layouts
- Button and TextView components
- Event handling
- `android:onClick`
- Java methods and conditions
- Calculator state management
- Number formatting and type casting

## Project Structure

- `MainActivity.java` – Handles the calculator logic and user interactions
- `activity_main.xml` – Defines the calculator user interface and layout

## Purpose

The purpose of this project is to apply Java programming concepts to a functional Android application and become familiar with the structure and development workflow of native Android applications.
